# 上岸 Android · 1.0.1 体验版

根据“上岸”网页账本的界面与记账规则重建的离线安卓 App。首次打开为空白真实账本，收入、开支、预留和预算均从 0 开始，由使用者填写。设置中可载入明确标记的独立虚拟演示。未填入用户历史真实债务。

## 安装与使用

1. 将 `shore-android-v1.0.1.apk` 下载到安卓手机并打开，按手机提示允许本次安装。使用原签名，可覆盖升级 1.0.0，无需卸载。
2. 支持 Android 8.0 及以上；使用更新后的 Android System WebView 或 Chrome。没有申请联网、通讯录、短信或广泛存储权限。
3. 在“借款”录入已有合同；已出账利息与费用请按本人账单填写。随后在“更多 → 记录收入”填写实际到账收入。
4. 记录还款前选择资金来源：收入、借贷、亲友支持。已有借入资金可关联使用，避免重复增加本金。
5. “更多 → 数据与设备”可保存 JSON 备份文件、选择文件恢复或使用备份文本。恢复前会校验并确认替换。卸载和清除 App 数据前请备份。

## 已提供

- 固定底部导航、独立内容滚动、Tab 滚动位置恢复和手机表单布局。
- 精简副标题、说明段落和装饰文案，保留关键数字、日期与操作提示。
- 总览、借款账本、逐月还款明细、每月预算与本金预测。
- 等额本金、等额本息、先息后本、每期固定费用的手动参数模型。
- 已有借款与新借入分开建档；新借示例次月首期。
- 实际收入、三类还款来源、关联借贷、亲友支持及归还。
- 金额以整数“分”运算；实际还款按费用、已出账利息、本金的顺序抵扣。
- App 私有数据保存、系统文件选择器备份与导入、原生复制、安卓返回键、会话内最近一次操作撤销。
- 预算不足时标记资金缺口，不显示可实现的结清承诺。

## 当前限制

- 这是离线体验版。没有自动云同步、账号、账单抓取、提醒通知或自动跨月结转。
- 账本固定在创建时的快照月份；预测是月度近似，不是平台实际逐日账单或提前结清报价。
- 当期本金按剩余本金、期数和模型计算；当期利息及费用使用手动填写的已出账值。没有填写的数值按 0 记录。
- 后续月份按年利率除以 12 近似；未知逾期费、信用卡循环利息、特殊减免、优惠和提前结清费用未计算。
- 固定费用账户不允许默认提前还本，不假定后续费用自动减免。人情债未加入平台结清预测。
- 备份未加密，仅支持本版本导出的 v3 格式，最大 2 MB。旧网页格式未自动迁移。
- 已通过账本逻辑、页面交互烟雾测试和 APK 签名校验；未进行安卓真机安装和视觉验收。

## 源码结构

| 路径 | 内容 |
| --- | --- |
| `app/src/main/assets/` | 离线页面、样式、账本引擎和界面逻辑 |
| `app/src/main/java/` | 标准 Android Java 工程；WebView、本机保存、备份文件选择 |
| `app/src/main/res/` | App 图标 |
| `offline/` | 与 Java 实现对应的 Smali 和资源清单，用现有本地工具打包 |
| `tools/build-offline.ps1` | 离线构建及签名校验脚本 |
| `tests/` | Node.js 内置测试，无 npm 依赖 |

## 继续开发

标准构建要求：JDK 17、Android SDK 35、Gradle 8.9；项目固定使用 Android Gradle Plugin 8.7.3、target SDK 34、min SDK 26。可将项目作为现有 Gradle 项目导入 Android Studio，再构建 APK；首次标准构建需要下载依赖。当前安装包使用本地现有 Apktool 2.11.1 和 apksigner 构建，不依赖 UniApp 或第三方 App 运行时。

已安装 Gradle 8.9 时：

```powershell
gradle :app:assembleRelease
```

运行测试：

```powershell
node --test tests/*.test.cjs
```

离线构建脚本需要提供 Java、Apktool、apksigner 和签名文件的实际路径，并安装 Python 3。可用 `-Python` 指定解释器；签名前会校验资源对齐。项目不附带第三方打包工具或 Android SDK。修改原生层时，优先使用标准 Java/Gradle 路径；若继续离线打包，需要同步修改对应 Smali。

## 保留升级签名

Git 仓库不包含 `private-signing/`、密钥库、口令、个人账本备份或安装包。此前交付的源码压缩包中保留了本体验版的签名资料，仅供本人私下保存；需要构建覆盖升级包时，可将其中的 `private-signing/` 单独放回项目根目录，不要加入 Git。后续希望覆盖安装并保留账本数据，需要使用相同包名 `cn.shore.ledger` 与相同签名；换签名通常需要卸载重装，请先备份数据。标准 release 构建发现此目录时会使用原签名；debug 构建使用调试签名，不宜覆盖本体验版。

参考：[Android 本地内容加载](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content)、[Android 命令行构建](https://developer.android.com/build/building-cmdline)。
